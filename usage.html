🛡️ 编码代理审计助手

如果 Cursor / Claude Code / Copilot 触发了安全告警，用这个页面生成“请 DSH 帮我查一下”的指令。不需要懂技术，照着填就行。

场景一：代理启动了一个我不认识的程序 最常见

比如告警说“某进程启动了 cmd.exe / powershell.exe”，你想知道是不是代理的正常行为。

在告警详情里找“Process ID”或“PID”。如果找不到，填 0 也可以，让 DSH 先看当前会话的父进程链。

场景二：代理读了敏感文件 高风险

比如告警说“某进程读取了 .aws/credentials 或 .ssh/id_rsa”，你想知道这是不是代理在做正常开发任务。

从告警详情里复制路径。常见敏感路径：C:\Users\你的用户名\.aws\credentials、C:\Users\你的用户名\.ssh\id_rsa

场景三：代理在对外连接 / 开了隧道 高风险

比如告警说“检测到 ngrok / ssh -R / 对外暴露端口”，你想知道这是不是代理的正常外联。

例如：ngrok http 8080、ssh -R 9000:localhost:22 user@host

高级：手动调用聚合报告（如果你已经拿到了三份证据）

先把三个采集工具的输出各复制一份，然后在这个框里每行放一个 JSON 字符串。

生成指令后，复制到 DSH 对话框里发送即可。DSH 会调用工具并把结果整理成你能看懂的报告。
